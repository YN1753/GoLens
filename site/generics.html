泛型直觉

泛型给函数/类型加类型参数 [T Constraint]，一份实现服务多种类型。 约束是类型集合（或接口），不满足则编译失败，不是运行时鸭子类型。

最小示例

func Map[T, U any](xs []T, f func(T) U) []U {
    out := make([]U, len(xs))
    for i, x := range xs { out[i] = f(x) }
    return out
}

约束

  • 接口约束：要求 T 实现某些方法。
  • 类型集合：int | float64 | string。
  • constraints.Ordered（golang.org/x/exp）表示可排序类型；标准库常见写法是自定义集合。

常见追问

泛型比 interface 快吗？

视场景。泛型减少装箱/断言，但 API 可读性更重要；先正确后优化。

能拿 T 做类型断言吗？

T 在函数体内的操作受约束限制；不能随意当 interface{} 乱断言。

速查表

  • [T Constraint] 类型参数 + 约束集合
  • 不满足约束 = 编译错误
  • 适合容器/算法；业务接口仍用 interface

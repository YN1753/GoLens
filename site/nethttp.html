net/http 服务模型

标准库 HTTP 服务器 = 监听 + 循环 Accept + 每个连接一个 goroutine 处理请求； IO 阻塞由 netpoller 摘离 CPU，因此能扛大量空闲连接。

骨架

http.HandleFunc("/", func(w http.ResponseWriter, r *http.Request) {
    // 尽量传 r.Context() 给下游
})
http.ListenAndServe(":8080", nil)

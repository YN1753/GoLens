Select 与定时器

select 同时等待多个 channel 操作：任一就绪则执行其一；多个就绪时伪随机选择； 全未就绪时阻塞，或立刻走 default。超时常用 time.After / Timer 作为其中一个 case。

基本形态

select {
case v := <-a:
    // 从 a 收
case b <- x:
    // 向 b 发
case <-time.After(d):
    // 超时
default:
    // 非阻塞
}

要点

  • 空 select select{} 永久阻塞（可用作「挂起主 goroutine」技巧，但要小心）。
  • 循环 + time.After 每次可能新建 timer，注意资源；热点路径用 time.NewTimer 并 Stop。
  • 与 ctx.Done() 组合是超时/取消的标准姿势。

常见追问

为什么 select 多个就绪还要随机？

防止某一 case 长期饿死，保证公平性（实现细节为伪随机）。

default 里能再写 select 吗？

可以，但容易把控制流写复杂；优先保持单层清晰。

速查表

  • 多路 channel 一起等；就绪随机挑一
  • default → 非阻塞；全空且无 default → 阻塞
  • 超时用 time.After / Timer + ctx

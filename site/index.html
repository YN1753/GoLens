拆成可以动手拧的旋钮

GoLens 是一本交互式八股手册：不堆定义，先把运行时过程画出来， 再让你一步步拧动状态。覆盖调度、数据结构、并发原语、内存与接口。

每章 Lab 都有 关卡剧本 + Go 代码观察窗：先跟「下一关」听生活隐喻，再对照高亮代码行，最后自己点按钮做实验。

设计原则

  • 面试直觉优先：叙事对齐 Go 1.21+ 常见讲解口径，刻意略去 sysmon 细节与屏障汇编。
  • 状态可观察：每个 Lab 都有事件日志，把「底层发生了什么」说成人话。
  • 零依赖：原生 HTML / CSS / JS，无 CDN，相对路径部署到 GitHub Pages 即可。

string 与 range

Go 的 string 是只读的字节序列（通常 UTF-8）。len(s) 是字节数； range s 按 rune 前进，下标是字节位置。中文/emoji 下两者差很大。

转换

  • []byte(s)：得到 UTF-8 字节，常用于 IO/哈希。
  • []rune(s)：按码点，适合按「字符」处理。
  • 频繁拼接用 strings.Builder，避免 + 产生大量临时 string。
经典坑

对含中文的字符串用 s[i] 或 s[i:j] 按「字符」切会截断 UTF-8，产生乱码。应先 []rune。

交互 Lab · 字节 vs 字符

怎么用：切换 ASCII / 中文 / emoji，再点 []byte、[]rune、逐步 range。

常见追问

string 可以原地改吗？

不能；底层字节视为只读。需要可变缓冲用 []byte。

range map 和 range string 顺序？

string 按 rune 顺序稳定；map 顺序故意随机。

速查表

  • string = 只读字节（UTF-8）
  • len=字节；range 按 rune，i 是字节下标
  • 字符处理用 []rune；拼接用 strings.Builder
